# Plattenspieler

Ein kleiner Plattenspieler im Browser. Du drückst auf Start: Der Tonarm schwenkt auf die Platte, die Platte dreht sich, und sobald die Nadel aufliegt, spielt der Song. Mit Stopp hebt die Nadel ab, die Musik verstummt sofort, der Arm schwenkt zurück und die Platte läuft aus.

- **Eine Taste** für Start und Stopp (der Kreis an der Arm-Achse macht dasselbe).
- **Zeitbalken:** Ein Klick darauf hebt die Nadel ab, der Arm schwenkt an die Stelle, dort spielt der Song weiter.
- **Regler rechts am Gehäuse:** stellt die Drehgeschwindigkeit der Platte ein (rein optisch).
- **Tag/Nacht-Umschalter** oben rechts.

## Starten
`index.html` im Browser öffnen. Es ist nichts zu installieren.

## Aufbau
- `index.html` – die ganze Seite (Plattenspieler, Steuerung, Design)
- `data/plattenspieler_song.mp3` – der Song
- `data/fonts` – Schriften (Comic Relief, M PLUS Rounded 1c, IBM Plex Mono)
- `data/favicon.svg` – Symbol im Browser-Tab
